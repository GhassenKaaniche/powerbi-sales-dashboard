This project presents an interactive sales dashboard built with Power BI using the Superstore dataset.

The dataset was cleaned and prepared using Python (Pandas), including data structuring and the creation of time-related features for analysis.

The dashboard provides insights into:

* Sales trends over time
* Sales distribution by region and segment
* Top 10 states by sales
* Top 10 products
* Sales by category and sub-category
* Category and segment analysis

The report consists of two pages:

1. Overview
2. Detailed Analysis
